# Task-Tracker-C
Simple Task Tracker program built in C and with Visual Studio 2022.

User interaction using the console. Each task has a Title and a checkmark for marking each task as Done.
User is able to view, add or delete tasks.
Tasks are saved in a text file, so the program can have memory for when it is used multiple times.
